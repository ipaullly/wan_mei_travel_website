# Technology Stack

## Frontend Technologies
- **HTML5**: Semantic markup with proper meta tags and accessibility considerations
- **CSS3**: Custom styling with animations, parallax effects, and responsive design
- **Bootstrap 5.3.7**: CSS framework for responsive layout and components
- **Google Fonts**: Cardo serif font family for typography

## Build System
This is a static website with no build process required. Files can be served directly from any web server.

## Common Commands
Since this is a static site, no build commands are needed. For development:

```bash
# Serve locally (using any static server)
python -m http.server 8000
# or
npx serve .
```

## External Dependencies
- Bootstrap CSS/JS from CDN
- Google Fonts (Cardo family)
- Placeholder images from picsum.photos for Instagram gallery

## Browser Support
Modern browsers supporting CSS Grid, Flexbox, and CSS animations. Bootstrap 5 provides cross-browser compatibility.
